02 · Motions

Eight motions, each for a specific job

Every study stays under 800 ms, eases out, and lands on the baseline without drift. Select a card to replay it with a new value. The playback speed above applies here too.

03 · Finishes

One geometry, six finishes

Set finish on the element. The metal and pearl finishes map each facet's brightness through a colour ramp, so the light still falls from the top left. Select a tile to catch the light.

04 · Get started

Install, register, set a value

Works in plain HTML, React, Vue and Svelte. TypeScript types are included.

1. Install

npm i facet-numerals

No build step? Load it from a CDN instead:

<script type="module" src="https://cdn.jsdelivr.net/npm/facet-numerals/src/define.js"></script>

2. Register the element

import 'facet-numerals/define';

Or call define('my-number') from the main entry to use your own tag name.

3. Use it

<facet-number value="2026" motion="roll" glint></facet-number>

Change value, as an attribute or a property, and the number animates to it.

Screen readers hear the number: the element sets role="img" and an aria-label with the current value. With reduced motion turned on, every change becomes a short crossfade.

05 · Motion tokens

Timing and easing tokens

Durations are at 1× speed. Stagger runs left to right across digit places, so the eye reads the number the same way it reads text.

MotionEnterExitEasingStaggerUse for
 
:root {
  /* Facet Numerals · motion tokens */
  --num-ease-out:    cubic-bezier(.16, 1, .3, 1);   /* roll, focus, settle */
  --num-ease-flip:   cubic-bezier(.2, .7, .3, 1);   /* flip, drop */
  --num-ease-in:     cubic-bezier(.5, 0, .75, 0);   /* every exit */
  --num-ease-glint:  cubic-bezier(.45, 0, .2, 1);   /* light sweep */

  --num-dur-exit:    170ms;
  --num-dur-focus:   320ms;
  --num-dur-pop:     360ms;
  --num-dur-flip:    420ms;
  --num-dur-drop:    460ms;
  --num-dur-glint:   700ms;
  --num-dur-roll:    380ms;  /* + 45ms per digit travelled */

  --num-stagger:     40ms;   /* per place, left to right */
  --num-cell:        56 / 80; /* tabular advance, cap 64, baseline 72 */
}
